# Learnly — React Native LMS MVP

A **demonstration** of the client's LMS mobile MVP requirements. Includes demo sign-in, categorized course dashboard, lesson reading/video-placeholder screen, quiz scoring, completion tracking and demo certificates. Built with React Native + TypeScript, Zustand and React Navigation.

## Important: demo limitations

- Auth and Google Sign-In buttons are **local demo interactions only**. They do not authenticate users or contact Google.
- All courses, lesson content and quiz answers are mock data in `src/data/courses.ts`.
- Video playback is **not connected**; the UI shows a placeholder.
- Learning progress is kept in **in-memory Zustand state** and resets after restarting the app.
- Certificates are **on-screen demo labels**, not downloadable verified documents.
- The supplied job post contains **no Figma assets or Swagger/API specifications**, so these integrations cannot be completed yet.
- No iOS/Android builds were compiled or run in this environment.

## Run it in a React Native CLI project

1. Install Android Studio (Android) / Xcode (iOS), Node.js and the standard React Native CLI prerequisites.
2. Initialize a compatible native React Native **0.78.2** project:
   `npx @react-native-community/cli@latest init LmsMobileMvp --version 0.78.2`
3. Copy `App.tsx`, `index.js`, `app.json`, `babel.config.js`, `metro.config.js`, `tsconfig.json` and the `src/` directory from this ZIP into the initialized project. Keep the native `android/` and `ios/` folders generated by the CLI.
4. Install navigation/state dependencies in the initialized project:
   `npm install @react-navigation/native @react-navigation/native-stack @react-navigation/bottom-tabs react-native-screens react-native-safe-area-context react-native-gesture-handler zustand`
5. iOS only: in `ios/`, run `pod install` (or `bundle exec pod install`, depending on your environment).
6. Run `npm start`, then `npm run android` or `npm run ios`.

## Production integration map

- `LoginScreen.tsx`: replace demo sign-in and Google button with real auth endpoints / OAuth provider setup.
- `courses.ts`: replace local samples with Swagger-defined course, modules, quizzes and student progress endpoints.
- `LessonScreen.tsx`: wire an authenticated video player to real streaming URLs, buffering and media caching.
- `store.ts`: persist sessions/progress and synchronize with backend.
- `ProfileScreen.tsx`: fetch certificate records from backend.
- Add token storage, endpoint error handling, refresh logic, telemetry, accessibility testing and real device QA.
